ОДОС — Открытая Диалоговая Обучающая Система

Описание проекта

ОДОС (Открытая Диалоговая Обучающая Система) — это интеллектуальная образовательная платформа класса «ИИ-репетитор», предназначенная для изучения теоретических дисциплин в интерактивном диалоговом режиме.

Система имитирует индивидуальное занятие с преподавателем: объясняет учебный материал, отвечает на вопросы учащегося, задаёт контрольные вопросы, анализирует ответы и сохраняет результаты обучения.

Основная цель проекта — предоставить преподавателям инструмент для создания собственных обучающих курсов на основе структурированной базы знаний и современных технологий искусственного интеллекта.



Основные возможности

Для учащихся:

1. Изучение учебного материала в диалоговом режиме.

2. Получение кратких и подробных объяснений.

3. Возможность задавать вопросы по изучаемой теме.

4. Работа через веб-интерфейс.

5. Текстовые ответы системы.

6. Голосовые ответы (в перспективе).

7. Анимированный аватар преподавателя (в перспективе).

8. Прохождение тестирования по изученному материалу.



Для преподавателей:

1. Создание собственной структуры дисциплины.

2. Наполнение базы знаний:

    2.1 текстовыми материалами;

    2.2 oPDF-документами;

    2.3 ссылками на проверенные ресурсы.

3. Настройка сценариев диалога.

4. Формирование перечня типовых запросов учащихся.

5. Создание или автоматическая генерация контрольных вопросов.

6. Назначение учебных материалов отдельным учащимся или группам.

7. Просмотр статистики обучения и журнала успеваемости.



Для администраторов:

1. Установка и сопровождение системы.

2. Управление учетными записями преподавателей.

3. Контроль работоспособности платформы.
